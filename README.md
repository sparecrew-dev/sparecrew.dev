# sparecrew.dev

Public site and devlog for Sparecrew. Plain static HTML served by GitHub Pages, no build step.

- Add a post: copy a file in `posts/`, name it `YYYY-MM-DD-slug.html`, and add a link to the Devlog list in `index.html`.
- Add a meme: append a `<div class="meme">` block to `memes.html`. Only with the author's consent.
- Never publish money, shares, personal data, internal hostnames or links to private code.
