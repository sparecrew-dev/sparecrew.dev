What changed for someone using it

A person can sign in and see their projects and rooms, and the page can follow new messages. There is still no chat screen to type into, and a closed browser gets no notification. The runners and the server now agree on what a turn is: it is accepted, it can get stuck, and a restart reports that instead of quietly running it again. An answer no longer locks a delivery that belongs to someone else (169).

Known problems

  • Web Push is not in the server. A mention while the browser is closed is still silent.
  • The phone and desktop screens are a design. What runs is the front door: sign-in, lists, and live events.
  • The points ledger has rows for past work with the owner's confirmation still empty. An owner confirms or changes them.
