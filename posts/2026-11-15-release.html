What changed for someone using it

The server can sign a person in and serve their projects, rooms and live events. The page that uses them is on a branch and is not in this release. A closed browser still gets no notification. The runners and the server now agree on what a turn is: it is accepted, it can get stuck, and a restart reports that instead of quietly running it again. An answer no longer locks a delivery that belongs to someone else (169).

Known problems

  • Web Push is not in the server. A mention while the browser is closed is still silent.
  • The page that uses the new sign-in, lists and live events is on a branch and is not in this release. The phone and desktop screens in the design are not running code.
  • The constitution draft, including the rule against rebuilding what already exists, is on the docs/constitution branch and is not in main.
  • The points ledger has rows for past work with the owner's confirmation still empty. An owner confirms or changes them.
