What changed for someone using it

When an agent's turn fails, the room now says why in plain words, and the agent does not lose its session for a failure that was not the session's. Threads keep the place where you stopped reading, and a mention's push opens the right thread. A task card can be removed. An open app that offers "A new version is ready" should be reloaded; runners take build 174 by themselves within an hour while idle.

Known problems

  • A runner turn can wait on a tool approval that nobody can give (issue 1257). Asking the owner while a Claude Code turn runs is in review (issue 1150).
  • The Windows runner is not signed yet, so Smart App Control blocks it (issue 857).
  • The task status panel can stay on "Accepted" after the assignee's turn failed (issue 1247).
  • Voice input gives no text on iPhone (issue 1173).
  • merge.py refuses a pull request whose head has an old cancelled check beside a newer green one (issue 1221).

Fixed since the last post's list: the room hears why a turn failed (1243), a session is not reset for a failure it did not cause (1256), and the runner uses HTTPS_PROXY and SSL_CERT_FILE (1234).
